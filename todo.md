# Cinema Studio — Deferred Features Roadmap

Features inspired by Higgsfield Cinema Studio 2.5 to be implemented in future iterations.

---

## Camera & Motion Control
- [ ] Optical camera control panel (camera paths, zoom, pan, focus depth)
- [ ] Camera preset library (dolly, crane, steadicam, handheld, etc.)
- [ ] Keyframe-based camera path editor with timeline

## Post-Production
- [ ] In-studio color grading suite
  - Color temperature (warm/cool)
  - Contrast & saturation sliders
  - Sharpness & effects
  - Highlights adjustment
  - Film grain control
  - Exposure control
- [ ] Apply color grade to keyframe before video generation
- [ ] Save and reuse color grade presets

## Multi-Shot Sequencing
- [ ] Timeline view for managing multiple shots
- [ ] Sequence editor with shot ordering and transitions
- [ ] Visual cohesion enforcement across shots
- [ ] Export assembled sequence as single video

## Soul Cast Enhancements
- [ ] Genre and era presets for characters (e.g., 1920s noir, cyberpunk 2080)
- [ ] Character avatar auto-generation via AI image model
- [ ] Budget/archetype-driven character quality tiers
- [ ] Skin texture and emotion control per scene
- [ ] Cross-scene character consistency enforcement
- [ ] Character expression/mood selector per shot

## Element Library
- [ ] Save and reuse locations as named presets
- [ ] Props library (vehicles, objects, weapons, etc.)
- [ ] Environment presets (weather, time of day, lighting)
- [ ] Shareable element packs between users

## Keyframe Preview
- [ ] Generate hero frame (still image) before committing to video generation
- [ ] Edit and refine keyframe before animation
- [ ] Support multiple keyframes for scene composition

## Zero-Prompting Options
- [ ] Replace prompt boxes with visual selectors where possible
- [ ] Dropdown-based scene composition (action verbs, camera angles)
- [ ] Drag-and-drop character placement on canvas
